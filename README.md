# 별길 (StarRoute)

별 관측 명소 추천 및 Pleos 내비게이션 연동 차량용 앱 프로토타입

## 1. 앱 소개
별길은 운전자가 별 관측 명소를 찾아 이동하고, 목적지에서 별자리 이야기를 체험하며 여행 기록을 남길 수 있도록 돕는 차량용 앱입니다.

## 2. 주요 기능
- GPS 기반 별 관측 명소 추천
- 관측 가능한 별자리와 추천 관측 시각·방향 안내
- Pleos 내비게이션 목적지 연동
- 목적지 접근 거리별 음성 안내
- 주차 상태 확인 후 별자리 이야기 체험
- 별빛도감 기록 저장
- 보름달 소원 안내

## 3. 개발 및 테스트 환경
- Android Studio
- Kotlin / Jetpack Compose
- Android API 34
- Pleos Connect v2.1.0 시뮬레이터
- Pleos Playground SDK

## 4. 실행 방법
1. Android Studio에서 프로젝트를 엽니다.
2. Gradle 동기화를 완료합니다.
3. Pleos Connect v2.1.0 시뮬레이터를 실행합니다.
4. `app` 실행 구성을 선택하고 Run을 누릅니다.
5. 차량 화면에서 별길 앱을 실행합니다.

Pleos 전용 SDK 및 시뮬레이터 환경이 필요합니다.

## 5. GPS 시연 방법
1. 별길 앱에서 개발용 GPS 테스트 설정을 엽니다.
2. 테스트 모드를 켭니다.
3. 김해천문대를 목적지로 선택합니다.
4. GPS 테스트 1단계, 2단계, 3단계를 순서대로 선택합니다.
5. 화면의 접근 안내와 음성 안내를 확인합니다.
6. 실제 내비게이션 경로 탐색 전에 테스트 모드를 끕니다.
7. 김해천문대를 선택하고 Pleos 내비게이션 경로 요청을 실행합니다.

## 6. APK
GitHub Releases의 **StarRoute v1.0.0**에서 `app-debug.apk`를 내려받을 수 있습니다.

본 APK는 Pleos 시뮬레이터에서 시험하는 디버그용 프로토타입입니다.
